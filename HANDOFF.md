## Requirements (from the user's voice brief, relayed via Codex)

1. New page where visitors drag sliders (spin, speed, power, weight; control also added) to build a table tennis setup.
2. Output: one blade (racket) and two rubbers that fit the slider values.
3. Works in reverse: pick the blade and rubbers, see the resulting slider statistics.
4. Every item lists full details (thickness, color, hardness, etc.).
5. Build the webpage first.
6. Write down one consistent, standardized, modular structure in a file so any future AI follows it and does not scatter messy code or resources.
7. Fit the current site to that structure and fix inconsistencies, keeping URLs, appearance and behavior unchanged.
8. Write this HANDOFF.md near the usage limit so Claude can keep working.
9. Delegate code work to Claude (voice agent only relays).
