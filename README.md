# Boson Chang — personal site

This is a static site published from the repository root. Page folders map directly to site URLs and keep each page's HTML, styles, scripts, data, and images together.

- `bc/` — personal homepage
- `cinema/`, `tabletennis/`, `vlog/` — media pages
- `apps/`, `contact/`, `diana/` — app information and personal pages
- `global/` — shared navigation, footer, styles, and scripts
- `handmade/` — preserved alternate copy; existing paths are left intact

Keep shared presentation and behavior in `global/`; page-specific assets stay with their page. Avoid adding generated previews or operating-system metadata to the repository.
